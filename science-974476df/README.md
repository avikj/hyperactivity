# Exact science modules — hyperactivity store 974476df

Each module below is a checked program: running it with the kernel re-derives every quantity and theorem it states from its definitions.

## Run
```
tar xzf science-modules.tar.gz            # the 126 module sources at their repository paths
git clone https://github.com/avikj/hyperactivity && cd hyperactivity && make   # or use cubical-linux-x86_64 from this bundle
./build/cubical chem/dirac.hypercubical    # any module path below
```

Modules import their dependencies by path, so run them from the repository root.
