## The project, in the owner's words

A cubical type theory language; whose normalization procedure and type check are terms of the
language; capable of expressing fully general computation (anything expressible in C++, as a
practical reference point); capable of interpreting any other language or computational system
(its syntax, interpreter and semantics as mathematical objects); capable of projecting
first-order terms to non-cubical languages, including machine code.

**The one rule.** No code is admissible unless it is proven correct by type check, correct by
construction and end to end. The only exceptions are a minimal trusted core and the untyped
definitions the checker itself is built from (bootstrap). No tests as evidence, no second copy
of a thing proved in place of the thing.

**The structural fact to know:** `Code` is declared before the checker exists, so a typed
definition cannot mention `Code`, `eval-g` or `quote` (`code: data type not checked: Code`).
Anything written over `Code` is therefore untyped. Every checked procedure about programs in
this library works over its own typed code type instead (`LinCode`, `ETm`, `Ex`, `Pl`,
`IntCode`). The language as it stands does check an indexed code type with a checked evaluator
(tried: 32 lines, context- and type-indexed terms, `refl` proves a code's meaning).

Every definition has a signature and checks (`Code`'s fields are typed in `lib/code.cub`; the
checker's services the compiler calls — a definition's code, conversion at a type, a
constructor's field count — are typed primitives at the end of `lib/std.cub`). Recursion the
checker cannot see as structural runs on fuel (`c-fuel = 2^14`) or `%welimP`.

Exercised: the 33 `#jit` workloads in `experiments/jit/workloads.cub` pass (`ok: jit`, each
checked by conversion or, with theorems, by the path checked as `f·jit`); `#build` of
`experiments/native/sys.cub` and `feed.cub` and `#build-loop` of `feedloop.cub` give the same
binaries as before, which run: `sys` writes `A` and exits 65; `feed` and `feedloop` print the
book's imbalance per message.

**What is checked** (`jit-plan`, `build-plan`): the specialized code is compared, by the checker's
own conversion, with the definition's value, and a rewrite along a theorem carries a path the
checker is given.

**What is not yet:** that the bytes compute what the specialized code computes. The statement:
`⟦bs⟧ a` places `a` where the entry expects it, runs `lib/isa/x86` and reads `rax` (the overflow
exit taken means the call is computed instead); correct is `f ≡ ⟦bs⟧`, checked per definition.
The proof is built from one theorem per byte pattern of the instruction table (its effect from
any frame state, by the model run on the literal bytes) as the encoder emits the bytes.

**Known behavioural defect:** `x-rel-fix` stops after 64 rounds and returns the set it has;
arguments not yet found needed are then erased to 0.

Also refused (untyped): `lib/derive.cub` (122 lines; `deriving eq` in the surface language is off
with it) and `lib/intlin.cub` (20).

`lib/compile/meaning.cub` (loaded after `lib/isa/x86/run.cub`) defines ⟦bs⟧: the blob at a fixed
address, the arguments' machine forms (`MForm`: word, Nat, Bool, pairs, lists, as `jit_in` places
them) in an array and the arena, the context and stack at fixed addresses; the model runs until
rip reaches the return address; the flag set (overflow exit) gives f's value. `Correct1/2 bs f`:
for every fuel and argument ⟦bs⟧ is f. `experiments/isa/jit-runs.cub` runs the compiler's bytes for
22 workloads under the Sail model (27 runs: loops, Nat recursion, closures, codata, division edge
cases, lists, pairs, records): every result equals the definition's (312M steps, ~2 min).

`experiments/isa/addw-all.cub` is a proof about one output of the untyped encoder at one fixed
placement, in the form PLAN and `tracks/README.md` forbid ("bytes with a lemma owed"); it is
superseded by the compiler at its type (paper §9.3; `tracks/E-lemmas.md`) and is to be deleted
when that checks. Its law files (`lib/compile/wordlaw.cub`, `bitlaw.cub`, `flags.cub`) are
usable.

`lib/compile/x86ok.cub` has lemmas about runs of the model (a run splits at any step; stores to
distinct addresses commute) for the template theorems.
