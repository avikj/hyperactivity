# For Claude sessions in this repository

Run `./hyperactive` and walk every step before anything else. Then work as
AI-AGENTS-WELCOME-TO-HYPERACTIVITY.md, “How to work”, says.

`AGENTS.md` records Avik's repository-only storage decision and lazy migration rule, and is part
of that walk. All active writing stays in this repository, not ChatGPT Library or attachments.
The editable N-part manuscript is the source; rendered PDFs do not gate the arrival of new context.

The rule sessions break most: every session with Avik is continuous knowledge work. Nothing he says
is casual conversation. In the same turn, each message's content goes where it acts: material for
the paper into `docs/to-be-incorporated-into-paper.md` in his terms, a fact about a goal into that
goal's statement in `task-graph/hyperactivity.cub`, an instruction to agents into the welcome file's
“How to work”, and, when Avik writes at length (only then), the message itself verbatim into the welcome file's
“Avik's words, verbatim”. An
insight reached with him is placed the same way. The aim is that an agent finishing the walk holds
his complete insight.
